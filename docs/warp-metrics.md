# Warp の寸法と文字サイズの実測

測定日：2026-09-09
対象：Warp のスクリーンショット 1958x1998 px
倍率：**2.00 倍**（macOS の信号機ボタンが 24px、標準は 12pt）

以下、`px` は画像上の実測値、`pt` はその 1/2。
帯の高さは文字のインクが載っている範囲であり、アセンダやディセンダを含む。
文字サイズはそこからの推定なので、推定と明記した。
アンチエイリアスのため ±1px の誤差がある。

## 1. 左ペイン

### 1.1 外形

| 項目 | px | pt |
|---|---|---|
| 左ペインの幅 | 396 | **198** |
| 行の矩形の幅 | 368 | **184** |
| 行の矩形の高さ | 130 | **65** |
| 行の送り（矩形の上端どうし） | 138 | **69** |
| 矩形と矩形のあいだ | 8 | **4** |
| 矩形の左余白（ペイン左端から） | 12 | **6** |
| 矩形の右余白（ペイン右端まで） | 16 | **8** |

窓の幅で左ペインの幅は変わる。
別のスクリーンショットでは 440px（220pt）だった。
行の矩形は左右の余白を差し引いた残り全部を使う。

### 1.2 行の中身

1 行は 3 段で構成される。

```
┌──────────────────────────────────────┐ ← 矩形の上端
│                                      │   上余白 22px（11pt）
│  ●   stock                    ⌘1     │ ← 1 段目 題名
│      ✻ Claude Code                   │ ← 2 段目 副題（送り 32px）
│      ⑂ main            [ +500 ]      │ ← 3 段目 枝と記章（送り 35px）
│                                      │   下余白 25px（12.5pt）
└──────────────────────────────────────┘ ← 矩形の下端
```

| 項目 | px | pt |
|---|---|---|
| 矩形の上端から 1 段目のインクまで | 22 | **11** |
| 1 段目から 2 段目（送り） | 32 | **16** |
| 2 段目から 3 段目（送り） | 35 | **17.5** |
| 3 段目のインクから矩形の下端まで | 25 | **12.5** |
| アバターの直径 | 36 | **18** |
| アバターの左余白（矩形の左端から） | 18 | **9** |
| 文字の左端（矩形の左端から） | 83 | **41.5** |
| 文字の左端（アバターの右端から） | 30 | **15** |
| `⌘N` の右端（矩形の右端から） | 23 | **11.5** |

### 1.4 文字サイズ

| 段 | インクの帯 | 内訳 | 推定サイズ |
|---|---|---|---|
| 1 段目（題名 `SES`、大文字のみ） | 19px | キャップ高 9.5pt | **13pt** |
| 2 段目（副題 `claude --dangerou…`） | 24px | 上端から下端 12pt | **12pt** |
| 3 段目（枝 `main`、小文字と `i` の点） | 15px | アセンダ 7.5pt | **10pt** |
| `⌘N` のヒント | 19px | キャップ高 9.5pt | 13pt（題名と同じ） |

推定は、キャップ高をおよそ 0.72 em、アセンダをおよそ 0.75 em として逆算した。
題名と副題で 1pt、副題と枝でさらに 2pt 落としている。

## 4. termit に移すときの換算

termit はウィンドウ全体を 1 枚の文字グリッドとして扱うので、pt をそのままは使えない。
セル数に直すと次のようになる（フォント 13pt、セル 7.83 x 17.0 px、倍率 1 のとき）。

| Warp | pt | termit のセル換算 |
|---|---|---|
| 左ペインの幅 | 198 | 約 25 桁（実測 220pt のときは 28 桁） |
| 行の送り | 69 | 約 4 行 |
| 行の中の段の送り | 16〜17.5 | 1 行 |
| 矩形の上下余白 | 11 と 12.5 | 各 0.7 行 |
| 矩形と矩形のあいだ | 4 | 0.24 行 |
| アバターの直径 | 18 | 1 行ぶん（2 桁ぶん） |
| 文字の左端（矩形の左端から） | 41.5 | 約 5 桁 |
| 本文の左余白 | 17.5 | 約 2 桁 |

**端数はセルに載らない。**
Warp の上下余白は合わせて 23.5pt（約 1.4 行）だが、グリッドでは 1 行か 2 行しか選べない。
termit では「内容の段数 + 余白 1 行」を採り、行の送りは
1 段のとき 2 行、2 段のとき 3 行、3 段のとき 4 行としている。
Warp の 69pt（約 4 行）は、3 段の行と一致する。

アバターは 18pt で、1 行の高さ（16pt）より少し大きい。
文字グリッドでは 1 セルに収める必要があり、そのままの比率では置けない。
termit がアバターを持たないのはこのためである。

## 5. termit の現状との差

| 項目 | Warp | termit（現状） |
|---|---|---|
| 左ペインの幅 | 198〜220pt | 32 桁（約 250pt） |
| 行の段数 | 3 段固定 | 1〜3 段（無い段は作らない） |
| 行と行のあいだ | 4pt | 1 行（16pt） |
| 段の送り | 16〜17.5pt | 1 行（17pt） |
| 文字サイズの階層 | 13 / 12 / 10pt の 3 段 | 全段 13pt（明度で 3 段） |
| アバター | 18pt の円 | なし |
| 記章（差分の行数） | あり | なし |

**文字サイズの階層は移せていない。**
単一の文字グリッドでは、段ごとにサイズを変えられない。
termit は代わりに明度で 3 段の階層を作っている（`#F8F8F2` / `#B0B1B0` / `#8A8B90`）。
サイズの階層を入れるには、左ペインを別のグリッドとして持つ必要がある。
